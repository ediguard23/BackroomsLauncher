# Imágenes generadas con IA

Los originales están en `fuentes-ia/`, sobre fondo magenta. Todo lo demás
(logos recortados, iconos, texturas del mod) sale de ellos con:

```bash
npm run imagenes
```

Generadas en Higgsfield el 2026-10-04 con **Nano Banana Pro** (1k, 2 créditos
cada una). El plan gratuito no deja usar GPT Image 2.5.
